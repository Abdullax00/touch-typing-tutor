# ⌨️ Офлайн-тренажёр слепой печати для компьютерных классов

Современный интерактивный тренажёр десятипальцевой слепой печати для детей и подростков, созданный специально для уроков компьютерной грамотности в школах и учебных центрах.

Программа разработана для **100% автономной работы без интернета** на каждом отдельном компьютере или в единой локальной сети компьютерного класса с общим рейтингом учеников.

---

## 🌟 Ключевые возможности

* **Полная автономность (100% Offline):** работает без доступа к интернету, внешних CDN и сторонних библиотек.
* **Автоматическая регистрация учётной записи ПК:** при запуске лаунчер автоматически определяет имя пользователя Windows (`%USERNAME%`) и имя компьютера (`%COMPUTERNAME%`), создавая персональный профиль для каждого ученика.
* **Смена отображаемого имени:** ученик или учитель может нажать кнопку **«✏️»** и указать реальные имя и фамилию (например, *«Артём Смирнов»*), сохранив привязку к учётной записи ПК.
* **Общий рейтинг класса (Leaderboard):**
  * Соревновательный пьедестал почёта Топ-3 с кубками и медалями (🥇, 🥈, 🥉).
  * 4 режима сортировки: ⭐ **По звёздам**, ⚡ **По скорости (СВМ)**, 📚 **По пройденным урокам**, 🎯 **По точности (%)**.
  * Подсветка строки текущего ученика в таблице лидеров.
  * Работает как локально на одном ПК, так и по сети класса через встроенный легковесный сервер `server.py`.
* **Эргономичная визуальная клавиатура и кисти рук:**
  * Интерактивные векторные кисти рук с цветовой разметкой зон каждого пальца.
  * Рельефные засечки на клавишах **[А]** и **[О]** опорного ряда.
  * Плавная анимация подъёма нужного пальца и подсветка противоположного Shift при наборе заглавных букв.
* **Обучающие видеоролики в HD качестве:**
  * Урок осанки и опорного ряда.
  * Эргономика рабочего места («Сиди прямо, будешь здоров!»).
  * Разминка для глаз и рук («Сделай перерыв и будь активным»).
* **Аркадная мини-игра «Воздушные шарики»:**
  * Игровой режим для закрепления пройденных букв и снятия напряжения на уроке.
* **Панель учителя (кнопка «⚙️ Учителю»):**
  * Возможность одним кликом разблокировать все уроки курса для свободного доступа.
  * Экспорт и импорт прогресса всех учеников в файл JSON.
* **Режим «📝 Свой текст»:**
  * Позволяет преподавателю задать собственный диктант, словарные слова или текст по теме урока.

## 🚀 Способы запуска

### Способ 1: Отдельное настольное приложение (Рекомендуется)
Дважды нажмите на файл:
👉 **`Тренажёр_Слепой_Печати.exe`**

* Запускается в режиме чистого окна (App Mode Chromium / Edge) без вкладок, закладок и адресной строки браузера.
* Не требует установки сторонних программ или прав администратора.

### Способ 2: Ярлык на Рабочем столе
1. Запустите файл **`Создать_Ярлык_на_Рабочем_столе.exe`** (один клик).
2. На Рабочем столе появится ярлык программы с фирменной иконкой клавиатуры.

### Способ 3: Сетевой режим для всего класса (с общим рейтингом)
1. На компьютере преподавателя запустите **`Запустить сервер для класса.bat`** (или `python server.py`).
2. В консоли отобразится локальный IP-адрес (например, `http://192.168.1.50:8080`).
3. Ученики открывают этот адрес в браузере со своих компьютеров — все результаты мгновенно транслируются на общий пьедестал почёта.

## 📁 Структура проекта

```text
├── index.html                           # Главный интерфейс тренажёра
├── styles.css                           # Стили оформления, адаптивная вёрстка и анимации
├── app.js                               # Контроллер приложения, логика набора и рейтинг
├── keyboard.js                          # Виртуальная клавиатура и анимация кистей рук
├── audio.js                             # Звуковые эффекты (Web Audio API)
├── game.js                              # Игра «Воздушные шарики»
├── course_data.js                       # База уроков, упражнений и инструкций
├── user_env.js                          # Данные учётной записи пользователя ПК
├── server.py                            # Локальный REST API сервер рейтинга класса
├── Launcher.cs                          # Исходный код C# лаунчера
├── Тренажёр_Слепой_Печати.exe          # Скомпилированный лаунчер Windows
├── CreateShortcut.cs                    # Утилита создания ярлыка на Рабочем столе
├── Создать_Ярлык_на_Рабочем_столе.exe   # Скомпилированный установщик ярлыка
├── videos/                              # Обучающие видеоролики в формате MP4
└── ИНСТРУКЦИЯ_УЧИТЕЛЮ.md                # Подробная памятка для преподавателя
```

## 🛠️ Стек технологий

* **Frontend:** HTML5, CSS3 (Flexbox/Grid, CSS Custom Properties), чистый Vanilla JavaScript (ES6+).
* **Аудио:** Web Audio API — процедурная генерация щелчков клавиш, звуков ошибок, фанфар и перезвона звёзд.
* **Бэкенд:** Python 3 standard library (`http.server`, без сторонних зависимостей pip).
* **Лаунчер:** C# (.NET Framework 4.0, встроен в Windows 10/11), запуск через Chromium `--app`.
